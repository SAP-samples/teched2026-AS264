# AS264 - Experience the Sourcing Assistant: From RFP to Award

## Description

This repository contains the material for the SAP TechEd 2026 session called AS264 - Experience the Sourcing Assistant: From RFP to Award.

## Overview

The **Sourcing Assistant** is an AI-powered procurement assistant in SAP Ariba, built into the Joule panel. In this hands-on session you work with its two specialist agents:

- **Sourcing Event Agent**: creates a sourcing event end to end, from a description of what you need to buy (or an uploaded document) to a published event in SAP Ariba with line items, suppliers, and evaluation questions.
- **Bid Analysis & Negotiation Agent**: analyzes supplier bids for a published event, produces a negotiation strategy, drafts supplier emails, and creates new bidding rounds directly in SAP Ariba.

## Requirements

- Access to the SAP Ariba test system used in this session (provided at the session).
- A current web browser (Google Chrome or Microsoft Edge recommended).
- For Exercise 3, the event ID (Doc ID) your instructor gives you.
